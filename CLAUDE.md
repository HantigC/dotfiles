## Repository Purpose

Personal dotfiles repository managed from `~/.config/dotfiles`. Config files are symlinked into their expected locations rather than copied.

## Structure

- `config` — a directory which contains configurations for multiple tools
- `cofing\vcode` - contains configurations for vscode
- `cofing\vcode\setup.sh` - create symlinks to for settings and keybindings, and installs extensions
- `cofing\vcode\settings.json` - system wide settigs for vscode
- `cofing\vcode\keybindings.json` - system wide keybindings for vscode
- `cofing\vcode\extensions.txt` - list of vscode extensions separated by newline
